# Portofolio Yuura

Website statis (HTML, CSS, JS). Tanpa build, langsung jalan di Vercel.

## File wajib (semua di akar repo, tanpa subfolder)
index.html, style.css, script.js, data.js, favicon.svg, vercel.json

## Yang kamu edit: data.js
- `email`: ganti dengan Gmail kamu
- `discord`: isi handle Discord kamu (kosong = disembunyikan)
- `KARYA`: judul, deskripsi, tahun, dan nama file gambar tiap karya

## File opsional (nama persis seperti di data.js / di bawah)
- `art-01.jpg` sampai `art-08.jpg`: karya kamu (rasio 4:5 paling pas, di bawah 3 MB tiap file)
- `hero.mp4`: video latar hero (5-10 detik, loop, di bawah 20 MB)
- `ritualface.jpg`, `velixir.jpg`: gambar kartu Build (rasio 8:5)

Tanpa file opsional, halaman memakai animasi aliran garis di hero dan seni placeholder di galeri.
Batas upload GitHub lewat browser: 25 MB per file.
